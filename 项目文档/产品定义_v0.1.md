# 自媒体通关搭档 产品定义 v0.1

## 一句话定位

给一个公开内容链接，返回一套有证据边界、能直接进入创作的原创内容方案。

## 目标客户

- 需要持续做短视频但缺少内容研究能力的商家或创作者。
- 有明确产品，却不会从对标内容提炼选题、脚本、钩子和评论需求的人。
- 愿意用发布结果持续迭代，而不是只购买一次性文案的人。

## 黄金用户路径

```text
提交抖音链接
  -> 采集公开标题、作者、指标、章节/字幕和评论
  -> 标注证据完整度与缺失项
  -> 蒸馏内容结构、钩子机制、观众问题与转化方式
  -> 结合客户产品资料生成原创脚本、标题、正文、CTA和评论回复话术
  -> 做平台与保健品风险检查
  -> 人工确认后导出内容包
  -> 后续回填发布结果，进入校准与复盘
```

## 产品不是

- 不是复制或洗稿工具。
- 不是医疗建议生成器。
- 不是平台账号托管或自动发布工具。
- 不是保证爆款的流量预测软件。
- 不是把 Claude Code、Codex 或内部 Skill 暴露给客户的聊天壳。

## Agent、Skill 和脚本的关系

- **产品**：客户访问的“自媒体通关搭档”网页。
- **Agent**：理解任务、选择步骤、整合证据并生成最终内容包的总负责人。
- **Skill**：Agent 内部的专项能力，例如抖音采集、内容蒸馏、脚本生成、保健品合规和发布复盘。
- **脚本/工具**：执行确定性动作，例如解析链接、提取字段、转写音频、匹配规则和导出报告。

客户只看到产品和结果。Agent、Skill、提示词、脚本与模型配置留在服务端。

## 甲方认可标准

1. 输入是真实公开链接，不是预先写死的一段营销文案。
2. 报告中的事实可以回到来源页面核对。
3. 明确区分“原内容事实”“Agent 推断”“客户产品事实”和“待确认项”。
4. 输出不止建议，至少包含一版可编辑完整脚本及配套发布文案。
5. 输出能说明为什么这样写、借鉴了什么机制、为什么不构成复刻。
6. 保健品功效、疾病、资质、适用人群等高风险表述必须进入发布前人工审核。
