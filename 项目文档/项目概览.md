# 项目概览

- 项目编号：024
- 项目名称：自媒体通关搭档
- 创建日期：2026-07-31
- 当前阶段：v0.3 电脑端快速看懂演示闭环（电脑端已验真；手机端延期）
- 产品形态：云端 Web Agent，客户只提交公开内容链接，不获得源码、Skill 或工作流
- 项目目标：把公开内容证据转成可复核的内容蒸馏、原创脚本、钩子、标题、正文、话术与平台风险提示，并用发布后反馈持续校准

## 能力来源

- 项目022：平台规则、发布前风险检查、公开链接采集经验
- 项目023：盲预测、评分、发布登记、复盘与 rubric 演进方法
- 项目019：内容实验数据模型、工作台交互与客户交付经验

三个旧项目保持独立，不直接作为客户运行依赖。项目024只吸收已验证的方法和必要代码思想。

## 第一阶段交付物

1. 抖音与 TikTok 单链接输入页。
2. 来源证据、数据完整度和采集边界。
3. 内容结构、钩子机制、观众需求和转化话术蒸馏。
4. 面向客户产品的原创内容包。
5. 保健品场景的医疗、功效、资质和绝对化用语发布前审核。
6. 公开链接自动采集失败时的明确重试提示，以及字幕/媒体人工降级入口。
7. Facebook、YouTube、X 可扩展的平台适配器契约。

## 当前边界

- 当前电脑演示支持抖音与 TikTok 公开单条作品链接；主页多作品、评论、画面 OCR 和镜头结构仍未接入。
- 抖音使用可替换的社区公共 Provider，不是官方稳定接口；服务变化、限流或无法解析时不能伪报采集完成。
- 不自动发布，不读取或导出 Cookie，不接触客户账号密码。
- 不把规则检查表述为法律意见或平台审核结论。
- 不承诺流量结果；没有历史账号数据时不输出伪精确播放预测。
- 演示样本只保存公开页面的必要证据、摘要和少量评论摘录，不复制完整视频。

## v0.3 用户路径

- 默认先展示一句话结论、内容结构、有效原因和可借鉴方法。
- 完整脚本、拍摄表、发布内容包、证据和风险改为按需展开。
- Web 默认请求 `analysis_mode=quick`；完整交付仍可使用 `analysis_mode=full`。
- 甲方电脑演示入口：项目根目录 `项目024_v0.3_甲方演示.cmd`，默认仅监听 `127.0.0.1:8792`；手机端局域网入口暂不纳入本轮验收。
- 按用户最新决定，电脑演示默认调用已配置的付费内容 API并直接生成完整研究稿；需要停用时使用 `-DisablePaidContent`。
