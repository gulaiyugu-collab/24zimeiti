# 项目概览

- 项目编号：024
- 项目名称：自媒体通关搭档
- 创建日期：2026-07-31
- 当前阶段：手机端云端最小闭环与小范围朋友内测准备；本机内容生产、账号运营和发布实验闭环继续作为研发基线
- 当前推进重点：收敛手机 MVP、受邀账号、云端任务状态、内测反馈和成本记录；安装包商业化作为后续方向
- UI 状态：用户已授权开始修改；“创作陪跑 / 安心交付”正式进入同一产品的两种体验模式
- 产品形态：当前先做手机浏览器云端 MVP，受邀朋友只获得使用权；后续根据真实需求再扩展 Windows 安装包、本地优先/云端兜底混合版和无电脑云端版
- 项目目标：把公开内容证据转成可复核的内容蒸馏、原创脚本、钩子、标题、正文、话术与平台风险提示，并用发布后反馈持续校准

## 当前产品愿景与设计注意事项

- 先验证需求，再扩大投入：第一阶段只做手机端云端最小闭环，邀请小范围朋友内测，记录完成率、重复使用率、失败原因、处理耗时、单位任务成本和可执行反馈。
- 内测只授予使用权：不交付源码、内部 Agent 协议、Skill、模型密钥或可转售的完整副本；内测协议需说明数据处理范围、反馈用途、服务可能中断和结果需人工复核。
- 一套能力内核、三种交付形态：手机云端版覆盖无电脑用户，Windows 安装包覆盖有电脑用户，混合版在弱设备上使用受控云端计算；不同时维护互相漂移的多套产品。
- 数据最小化与主动交付：优先公开链接、用户主动导出的 CSV/XLSX、本地同步助手或客户自有存储；不上传 Cookie、密码、浏览器 profile 或 OAuth token，不把绕过平台权限的方案作为产品能力。
- 云端处理必须透明：明确数据去向、传输内容、保存期限、删除策略、使用的 Provider/模型和可能产生的费用，不能静默切换远程 OCR 或正式生成。
- 权益保护优先：安装包后续采用授权使用权、签名更新、设备迁移、合理离线宽限期和源码/密钥隔离；客户数据归客户，通用代码、算法、提示词体系和商标归项目方。
- 正式生成费用单独管理：软件授权费与远程 OCR/模型生成额度分开核算，不能把你的总 API Key 放入安装包，也不承诺终身无限远程处理。
- 任何平台采集、AI 生成、合规判断和流量结果都要保留证据边界，不把研究稿、规则提示或机器推断描述成平台保证。

## 当前边界

- 当前电脑演示支持抖音与 TikTok 公开单条作品链接，并可对已登记来源视频提取代表帧、估算候选镜头切点和节奏、使用本地 RapidOCR 识别代表帧文字，并用本地 Ollama 模型分析 4 张精选帧的人物、物体、动作、场景和构图；主页多作品与评论仍未接入。
- 本地多模态结果只代表抽取帧，观察与推断分开保存；复杂分屏、细小物体和画面内文字可能误判，必须通过对应帧复核。
- 抖音使用可替换的社区公共 Provider，不是官方稳定接口；服务变化、限流或无法解析时不能伪报采集完成。
- 不自动发布，不把 Cookie、密码或浏览器登录态写入项目、日志、数据库或云端；本机导出助手仅在用户主动点击时复用浏览器会话并在导出后清理。
- 不把规则检查表述为法律意见或平台审核结论。
- 不承诺流量结果；没有历史账号数据时不输出伪精确播放预测。
- 账号数据以自动连接和同步为主路径；当前本机浏览器助手是研发实现，线上需演进为官方 OAuth 或用户侧安全连接器。CSV/XLSX 只保留为故障兜底；不保存原文件、密码、Cookie 或 OAuth token。
- 演示样本只保存公开页面的必要证据、摘要和少量评论摘录，不复制完整视频。

## 当前用户路径

- 默认先展示一句话结论、内容结构、有效原因和可借鉴方法。
- 完整脚本、拍摄表、发布内容包、证据和风险改为按需展开。
- Web 默认请求 `analysis_mode=quick`；完整交付仍可使用 `analysis_mode=full`。
- 当前本地研发服务仅允许回环监听 `127.0.0.1:8792`；账号数据与付费 Agent 尚无线上访问控制，不能把本机运行状态描述为已部署。旧 v0.2 交付目录已移入 `产出\\归档`，不再作为活动版本。
- 按用户最新决定，电脑演示默认调用已配置的付费内容 API并直接生成完整研究稿；需要停用时使用 `-DisablePaidContent`。
- 抖音分析结果可保存为服务端选题，通过稳定内容编号进入 `/static/douyin.html` 管理，并携带同一编号进入发布实验；TikTok 运营板块本轮未实施。
- `/static/douyin.html` 以自动连接账号为主路径，文件导入降级为兜底；账号建议只比较自身相邻时段。三个主页面继续提供 Agent 小窗。
- Web 是唯一活动产品；服务器部署、账号体系、租户隔离、计费与真实手机验收列入 P4 主线，小程序或原生 App 暂不投入。
- 新对话先读取项目根目录 `PROGRESS.md`、`feature_list.json`、本文件与 `产品定位与线上化路线.md`。
