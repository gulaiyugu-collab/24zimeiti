# Web 应用 v0.3 简化与提速

## 本轮目标

把开发版从“先展示完整专业报告”改为“先让普通人快速看懂，再按需展开完整能力”。旧甲方验收包不覆盖，原有完整脚本、拍摄表、发布包、证据和风险字段继续保留。

## 用户路径

```text
粘贴公开视频链接
  -> 快速看懂
  -> 一句话结论 + 3 条内容结构 + 3 条有效原因 + 3 条可借鉴方法
  -> 查看完整脚本或补充资料生成原创稿
  -> 按需展开拍摄表、发布内容包、证据和风险
```

界面不再要求用户先理解 Agent、ASR、Provider、Schema 等内部概念。字幕、媒体和商品资料收进“需要时再补充资料”。

## 代码能力

- 应用版本升级为 `0.3.0`。
- `AnalyzeRequest.analysis_mode` 支持 `quick` 和 `full`，API 默认继续兼容旧 `full`，Web 默认使用 `quick`。
- `quick` 使用独立短提示和最多 900 token 的 JSON 结果，只返回快速解读，不等待完整拍摄表和发布包。
- 登记样本直接从已审阅报告生成 `quick_result`，不调用模型。
- `full` 保留 v0.2 完整研究稿路径。
- 快速视图每组默认最多展示 3 条，完整字段在展开区保留。

- Python 编译通过。

- 已授权的真实 DeepSeek 验收中，快速结果约 4.97 秒，完整研究稿约 10.07 秒；两者均返回 HTTP 200。

## 仍未完成的边界

- 当前实现已接入抖音与 TikTok 实时单链接、代表帧和候选镜头结构；画面文字 OCR 与公开评论采集仍未接入。本文其余内容保留为 v0.3 简化阶段的设计记录，动态状态以 `PROGRESS.md` 和 `feature_list.json` 为准。
- 真实局域网手机访问尚未验真；Windows Private 防火墙当前存在 Python 入站 Block 规则，调整需用户确认。
- 本轮真实样本为英语短视频，多语言准确度与长视频性能仍需扩展验证。
- 不读取 Cookie、密码、浏览器本地存储或个人登录态，不自动发布内容。
