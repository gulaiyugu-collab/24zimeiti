# 项目024：自媒体通关搭档

重点建设的线上自媒体工作台。用户粘贴公开抖音或 TikTok 单作品链接，系统负责采集媒体、提取或转写字幕、生成内容研究稿，并保留证据和发布前审核边界。

当前 Windows 本机 Web 应用是研发和真实能力验真环境，不是最终安装包或甲方验收版。目标形态是服务器部署、浏览器持续使用，并在真实用量计量后选择按量、套餐或额度制。产品定位与线上化边界见 [`项目文档/产品定位与线上化路线.md`](项目文档/产品定位与线上化路线.md)。

当前活动应用位于 [`工作文件/app`](工作文件/app)，项目状态以 [`PROGRESS.md`](PROGRESS.md) 和 [`feature_list.json`](feature_list.json) 为准。

## 已验真能力

- 抖音与 TikTok 公开单链接采集。
- 抖音公共 Provider 失效时使用无个人登录态的隔离浏览器回退。
- 抖音合并媒体与分离音视频流均可处理；最终媒体进入 ASR 前强制检查视频流和音频流。
- 本地 `faster-whisper` GPU 字幕转写与带时间码分段。
- 完成任务缓存、过期短链的本机失败恢复、精简证据清单和 SHA-256 校验。
- 已登记来源视频的本机代表帧提取、候选镜头结构估算、RapidOCR 画面文字识别与 Ollama 多模态精选帧分析；OCR 与人物/物体/动作/场景观察分层保存，观察和推断可回到具体时间点与帧。
- 完整口播以无时间码的连续正文展示和复制；OCR 与视觉时间线继续保留时间证据。
- 已配置环境下的 DeepSeek 研究稿、拍摄表和发布内容包；证据不足时强制 `publishable=false`。
- 商品属性自动分流：商品、非商品和待确认内容分别处理；商品字段只在商品改写或正式发布时参与资料门槛。
- 资料缺口分为当前解读必需、可选增强和商品改写/发布三类；模型完成解读后不保留旧的“内容蒸馏缺失”提示。
- 发布实验闭环：核心登记只要求标题和平台，7 维自评与 T+72h 指标区间是默认折叠的可选复盘基线；无基线也可发布、回填和复盘。状态严格按 `predicted → published → measured → reviewed` 推进，SQLite 当前状态与不可更新/删除的追加事件分开保存；样本不足 3 条时只提示“证据不足”。页面位于 `/static/publish.html`。
- 抖音运营板块：分析结果可保存为带稳定内容编号的抖音选题，服务端 SQLite 持久化后可搜索、筛选、更新状态并带入发布实验。页面位于 `/static/douyin.html`。
- 抖音账号档案：可从创作者中心导入 CSV/XLSX，也可在用户主动点击后由本机浏览器导出助手复用会话并立即导入；二维码登录成功后，助手会继续轮询并自动寻找导出按钮。按该账号自身相邻时段分析播放、留存、包装、互动和粉丝变化。原文件、密码、Cookie 和 OAuth token 不落盘，浏览器 profile 只作临时会话使用。
- 页面内 Agent：内容分析、抖音运营和发布校准页可持续讨论并写回脚本或运营策略；每次发送调用一次已配置内容模型并产生 API 用量。

官方抖音 OAuth 尚未接通：官方入驻文档当前将网站/移动应用列在企业身份范围，个人主体仅支持小游戏和小玩法；即使具备合规主体，还需要应用上线、HTTPS 回调、scope 审核和真实授权验收。当前按钮会如实显示该边界，不会伪造登录成功。

## 本地研发运行

要求 Windows、Python 3.11+、Node.js、Chrome 或 Edge、`ffmpeg` 与 `ffprobe`。本机画面语义使用免费的 Ollama `qwen2.5vl:3b`，不需要账号或 API Key；当前入口会自动启动已经安装在项目 G 盘缓存中的模型，缺失时如实降级。首次运行先安装浏览器探测依赖：

```powershell
Set-Location 'G:\Workspace\Projects\项目024_自媒体通关搭档\工作文件\app'
npm install
```

从项目根目录启动当前本地研发入口：

```powershell
.\demo-v03.ps1
```

默认访问地址为 <http://127.0.0.1:8792>；抖音运营页为 <http://127.0.0.1:8792/static/douyin.html>。完整启动和环境说明见 [`工作文件/app/README.md`](工作文件/app/README.md)。

## 仓库边界

仓库不包含本机虚拟环境、模型、缓存、真实采集媒体、运行任务、日志、素材、生成产物或 API 凭据。模型与运行依赖需要在目标电脑上按文档安装；付费内容生成只有在服务端环境已配置凭据时才会启用。

当前仍未接入公开评论和主页多作品采集；本地 OCR 最多覆盖 12 张代表帧，本地多模态模型只分析其中 4 张精选帧，复杂分屏和细小物体仍需人工打开对应帧复核。候选镜头切点仍只是机器估算，真实手机访问验收为延期项。
